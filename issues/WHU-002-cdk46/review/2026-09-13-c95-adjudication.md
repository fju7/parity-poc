## C95-001 — the spending function and the boundary, un-conflated

**What changed.** Two sentences rewritten. Body: "…and spent across interim
and final analyses under an O'Brien-Fleming spending function." → "…under a
Lan–DeMets spending function with an O'Brien–Fleming boundary." MONARCH 3
source note: "…by the Lan-DeMets method with an O'Brien-Fleming spending
function, with alpha divided…" → "…by a Lan–DeMets spending function with an
O'Brien–Fleming boundary, with alpha divided…".

**Why.** Gate finding c95 (WRONG_VALUE, 31 August): both sentences called
O'Brien–Fleming the spending function; the second also named Lan–DeMets as
"the method". S003's statistical section, read on the rendered page (F1,
pdftoppm 200 dpi, page 2 right column continuing at the top of page 3):
"The cumulative type I error rate within each population was maintained using
the Lan–DeMets spending function with O'Brien–Fleming boundary used to control
multiplicity for all the interim and final analyses." The PDF's text layer maps
the dash in both names to the letter "e"; F2 (a rendition with a sound layer)
was attempted and refused — Europe PMC inEPMC N; annalsofoncology.org and
sciencedirect.com 403 to a script; no browser connected — so the defect is
declared on S003's record (`text_layer: defective`, F3) and the quotation
check reports cannot-evaluate against it.

**Who decided.** The advisor's directive of 13 September ("c95 rendition, then
the correction"), confirmed in the directive of the same day ("two
confirmations before you record"); applied by Claude Code.

**Effect on this assessment.** None on any figure. The name of the method
changes.
